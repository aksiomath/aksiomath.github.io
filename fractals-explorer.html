Project Deep Dive

Fractals & Complex Dynamics Explorer

A GPU-driven Qt application that renders Mandelbrot, Julia, Multibrot, and Newton fractals with ultra-deep zoom, smooth coloring, and adaptive performance tuning.

Key Features

Multiple Fractal Types

Renders Mandelbrot, Julia, Multibrot, and Newton fractals with smooth coloring algorithms and parameter exploration.

Ultra-Deep Zoom

Supports zoom levels up to 10⁻¹⁵ with arbitrary precision arithmetic for exploring microscopic fractal details.

GPU acceleration

Hardware-Accelerated Rendering

Leverages OpenGL shaders for real-time rendering at 60 FPS with adaptive performance tuning.

Color mapping

Smooth Coloring

Advanced coloring algorithms including continuous potential, orbit traps, and custom palettes.

Technical Architecture

Qt 6 & OpenGL

Built with Qt 6 and QOpenGLWidget for hardware-accelerated rendering with custom fragment shaders.

Arbitrary Precision

Uses MPFR library for arbitrary-precision arithmetic to maintain accuracy at extreme zoom levels.

Interactive Exploration

Mouse-driven pan and zoom with keyboard shortcuts for parameter adjustment and preset management.
