Project Deep Dive

Maze & Pathfinding Visualizer

A Qt desktop app that combines advanced maze generation and graph search visualization with interactive terrain costs, algorithm selection, and heatmap insights.

Back to Portfolio → View Details →
01 / 02
Key Features
G(n) + H(n)

Multiple Algorithms

Supports BFS, Dijkstra, A*, and greedy best-first search with real-time visualization and comparison.

DFS · Prim · Kruskal

Maze Generation

Dynamic maze generation using DFS, Prim's algorithm, Kruskal's algorithm, and Wilson's algorithm.

Terrain costs

Weighted Graphs

Interactive terrain cost controls for testing pathfinding on weighted graphs with obstacles.

Heatmap analysis

Visualization Tools

Color-coded heatmaps showing visited nodes, path costs, and algorithm exploration patterns.

02 / 02
Technical Architecture

Qt 6 Graphics

Built with Qt 6 QGraphicsView for efficient grid rendering and interactive cell manipulation.

Graph Algorithms

Implements standard graph data structures with priority queues for optimal search performance.

Real-time Animation

QTimer-based animation system with adjustable speed controls for step-by-step algorithm observation.

Insight

Pathfinding algorithms reveal optimal routes through complex networks.

// A* combines the benefits of Dijkstra and greedy search.
// It uses both actual cost from start (g) and heuristic estimate to goal (h).
