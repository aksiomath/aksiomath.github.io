Project Deep Dive

Sorting Algorithms Visualizer

A Qt application that animates 10 sorting algorithms with timeline scrubbing, pseudocode highlighting, and event logging for algorithm education and performance comparison.

Back to Portfolio → View Details →
01 / 02
Key Features
O(n log n)

10 Algorithms

Visualizes Bubble, Selection, Insertion, Merge, Quick, Heap, Shell, Counting, Radix, and Bucket sorts with animated comparisons.

Timeline

Timeline Scrubbing

Interactive timeline for stepping through algorithms forward and backward with frame-by-frame control.

Pseudocode

Code Highlighting

Real-time pseudocode highlighting synchronized with animation for understanding algorithm logic.

Statistics

Performance Metrics

Live comparison of comparisons, swaps, and time complexity with distribution controls.

02 / 02
Technical Architecture

Qt 6 Animation

Built with Qt 6 QTimer and custom widgets for smooth 60 FPS animations with adjustable speed.

Algorithm Library

Clean C++ implementations of all sorting algorithms with standardized interfaces for comparison.

Event Logging

Records every comparison and swap for timeline scrubbing and step-by-step replay capability.

Insight

Sorting algorithms illustrate fundamental trade-offs in computational efficiency.

// QuickSort averages O(n log n) but degrades to O(n²) on already sorted data.
// MergeSort guarantees O(n log n) but requires O(n) additional space.
// The choice of algorithm depends on data characteristics and constraints.
// Visualizing these trade-offs builds intuition for algorithm selection.
