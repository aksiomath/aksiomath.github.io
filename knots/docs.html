The .aknot file

An .aknot file is indented JSON in UTF-8. It stores a knot twice: as a recipe (which knot, with which settings) and as the points of the curve that was on screen. You can read it in any text editor.

{
  "format": "AKSIOMA Knots",
  "version": 1,
  "name": "Trefoil Knot",
  "knot": { "type": "trefoil", "p": 3, "q": 2, "table": "", "custom": "" },
  "shapeChanged": false,
  "points": [ [0.391, -0.978, -0.233], [0.196, -0.995, -0.118] ],
  "appearance": {
    "thickness": 0.16,
    "samples": 160,
    "material": 3,
    "shine": 0.0,
    "colorMode": 0,
    "color": "#bab9b4"
  }
}

The program writes the keys in alphabetical order, one number per line. Order does not matter when reading. The list of points above is shortened.

Which copy wins when opening

  • Normally the recipe: the knot is rebuilt cleanly and keeps everything the program knows about it.
  • If shapeChanged is true, the knot takes the saved shape, point for point, and keeps its name.
  • If the type or the table name is unknown, the points open as a custom curve.

Saving is safe: the file is written aside and swapped in only when complete, so a crash cannot leave half a file.

Reading one in Python

import json

with open("Trefoil Knot.aknot", encoding="utf-8") as f:
    knot = json.load(f)

assert knot["format"] == "AKSIOMA Knots"
xs, ys, zs = zip(*knot["points"])
print(knot["name"], knot["knot"]["type"], len(xs), "points")

Text and CSV import

Open, and dragging onto the window, also take .txt and .csv files. The result is a custom curve named after the file.

  • If the text contains an = sign it is read as a formula.
  • Otherwise only lines that start like a number are read, so headers and # comments are skipped.
  • Each line holds three numbers separated by commas or spaces. Round and square brackets are ignored.
  • At least three points are needed. The last is joined back to the first.
  • If the file has several # component blocks, only the first is opened, with a notice.
# exported from a script
x, y, z
1.000, 0.000,  0.000
0.309, 0.951,  0.250
(-0.809, 0.588, 0.000)
-0.809 -0.588 -0.250

A curve smaller than 0.25 or larger than 25 units in radius is scaled to a comfortable size.

Formula reference

Define x, y and z in the variable t, which runs from 0 to 2π. Separate them with new lines or semicolons.

x = (2 + cos(2t)) cos(3t)
y = (2 + cos(2t)) sin(3t)
z = sin(4t)

Limits and errors

  • Each formula may be up to 4000 characters.
  • The program names the failing line: an unknown name, a comma in a number, a place it could not read, or a value that does not exist (division by zero, root or logarithm outside its range).
  • A curve that does not come back to its start has its ends joined with a straight piece, which becomes part of the knot, and the program says so.

How invariants are found

Where a value comes from depends on where the curve came from. The note under the polynomials in the program always says which case applies.

CurveSource of the values
Built-in presets and torus knotsExact values for the knot type.
Knot tableValues from KnotInfo.
Custom, drawn, joined or retied curvesComputed from the curve, as below.
Several strandsGauss linking numbers. Polynomials of links are not computed.
  • Alexander polynomial: computed exactly by Fox calculus from a projection of the curve, and checked on a second projection when possible.
  • Jones polynomial: from the Kauffman bracket, when a projection with at most 24 crossings is found.
  • Identification: the knot is looked up among all prime knots with up to 13 crossings and composite knots with up to 8. A knot with more crossings can share both polynomials, so the answer starts with "Probably".
  • Writhe and crossing counts are measured on the 3D curve and depend on its shape.
  • Determinant is |Δ(−1)|. A knot can be tricoloured exactly when 3 divides it.

Without a Jones polynomial, mirror images are not told apart.

Knot data and conventions

The table holds the 12,965 prime knots with up to 13 crossings, with their 3D shapes, names and invariants, from KnotInfo:

C. Livingston and A. H. Moore, KnotInfo: Table of Knot Invariants, retrieved October 24, 2026.

  • Names follow KnotInfo: 8_19, and from 11 crossings 11a_367 (alternating) or 11n_34 (non-alternating). Search accepts 11n34 too.
  • Torus knots T(p,q) with positive p and q are the positive ones.
  • The right-handed trefoil has Jones polynomial −t⁴ + t³ + t.
  • On a Seifert surface, amber is the side from which a Seifert circle runs anticlockwise. The matrix entry V[i][j] is the linking number of loop i with loop j lifted off the amber side.

On your computer

The program works offline. These are the places it writes to.

PlaceContents
%LOCALAPPDATA%\AKSIOMA\AKSIOMA KnotsAutosaved work, discarded recoveries (kept for 7 days), a cache and aksioma.log, which starts again once it passes 1 MB.
HKCU\Software\AKSIOMA\AKSIOMA KnotsSettings, window layout and recent files.
HKCU\Software\Classes\.aknot and …\AKSIOMA.KnotThe file type, its icon and the open command.

The program renews the file type at every start, so if you keep two copies, .aknot files open in the one you started last.
